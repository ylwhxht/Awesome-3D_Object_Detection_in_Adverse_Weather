# Literature update — October 12, 2026

This expanded review adds **44 distinct works** beyond the earlier 11-work update on the same day. Of these 44 additions, **27 are listed under 2026 and 17 under earlier publication years**. These are publication/online-first year buckets, not a count of papers first released within the last six months. Earlier preprints and later journal issue assignments are identified below.

After consolidating three duplicate representations, the bibliography contains **192 distinct papers/resources across 213 category entries and 10 research tracks** (previously 151 distinct resources and 163 entries). Cross-listing a dataset or benchmark in another relevant track does not create another paper.

## Scope and search

The review covers adverse-weather 3D detection and its supporting data, simulation, restoration, robustness analysis, LiDAR/camera/radar fusion, and cooperative perception. Rain, fog, snow, spray, dust, and related visibility degradation were searched. Camera-only 3D detection and established datasets omitted from earlier versions were explicitly backfilled.

Searches combined sensor/task/weather terms, named-method follow-ups, venue searches, and references from relevant papers. Sources checked include arXiv, official CVF proceedings, NeurIPS proceedings, ICRA/ICASSP program pages, IEEE publisher records, journal publishers, author project pages, and author repositories. Publisher-deposited Crossref metadata was used to resolve DOI/title/venue discrepancies. The retained local query log contains 108 query strings, in addition to targeted source and repository checks. Retrieval cutoff: **2026-10-12**. This is a broad curated update, not a claim of an exhaustive systematic review.

Inclusion requires an explicit connection to adverse weather/corruption evaluation, a directly relevant weather dataset, or a supporting simulation/analysis method. Generic radar papers were not added solely because their introduction describes radar as weather-robust. Pure 2D restoration, occupancy, segmentation-only, SLAM, and planning papers were outside the new detection-focused additions, except clearly labeled supporting weather analyses. Existing broader background entries were retained. New MDPI papers were excluded under the literature-search workflow's source policy; existing entries were retained and wrong links corrected, so coverage of that publisher is intentionally incomplete.

Paper, project, code, and data links are labeled separately. A repository or promised release alone was not treated as working public code. Fifteen linked GitHub resource repositories were inspected; code labels require actual implementation or SDK files. This checks availability and file presence, not execution or reproducibility of the external projects.

## Verification boundary

Titles, venue/status, weather relevance, duplicate identity, and available resource labels were checked for the new entries; the exceptions above distinguish metadata-only or author-reported evidence. This review does not certify all inherited bibliography entries or reproduce any paper's experimental results. Source availability and release status are snapshots at the retrieval date.
